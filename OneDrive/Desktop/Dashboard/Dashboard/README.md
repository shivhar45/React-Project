# 📊 React Dashboard

A simple user analytics dashboard built with **React + Vite**.  
It includes charts (Recharts), user listing, modal with cross-close button, and modern styling.

---

## 🚀 Features
- Total users tile
- Users created per day (Line Chart)
- Avatar distribution (Pie Chart)
- User list with avatars, email, role
- Click row → shows modal with user details
- Modal with **cross (×) close button**
- Dark themed UI with modern styling

---

## 🛠️ Tech Stack
- React (Vite)
- Recharts
- CSS (custom styling)

---
